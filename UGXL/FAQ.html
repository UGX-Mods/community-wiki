Installation

What do I need to run the UGX Launcher?

Windows Vista or later and Call of Duty: World at War. The UGX Launcher also needs the Visual C++ 2013 runtime, which the UGXL Installer checks and installs for you (see Application Dependencies ).

How do I install the UGX Launcher?

Download and run the UGXL Installer, then follow the steps of the install wizard. See Getting started for the download link and Install for the steps.

My antivirus or firewall blocks the UGX Launcher

The UGXL Installer checks for security applications that are known to cause problems and can whitelist the UGX Launcher in the Windows Firewall. See Security Applications check , Firewall Whitelisting and Better Anti-Virus handling .

Why does the UGX Launcher need admin rights?

The Windows User Account Control blocked the old UGX Map Manager from installing files into the World at War mods folder. The UGX Launcher therefore requires admin rights and tells you if your UAC settings need to be changed (see UAC Check ).

How do I uninstall the UGX Launcher?

Use the UGXL Installer or the Windows Programs and Features list, see Uninstall .

Account

I can't log in

  • Log in with your UGX-Mods account credentials. Use your account name , not your display name (see Rename user and account ).
  • The login is case sensitive, check that Caps Lock is off.
  • Try to log in on ugx-mods.com to check your credentials.

More in How to Login into UGX Launcher and Troubleshooting .

Can I use the UGX Launcher offline?

No, there is no offline mode yet. It is planned for the future (see Known Issues and limitations ).

Maps and mods

How do I install and play a map?

Click Install on the map in the map view, wait for the download and installation, then start it from the UGX Launcher. See How to Install a Map or Mod and How to Play a Map or Mod .

The UGX Launcher says a map has disallowed files

The UGX Launcher checks that each map folder only contains the files of the mapper. Additional or modified .iwd and .ff files and subfolders are not allowed. It offers to delete them; if you want to keep them, choose No / Skip and move them out of the map folder. See Disallowed files .

A map needs T4M. What is that?

T4M extends World at War with higher asset limits and other features some maps need. The UGX Launcher installs it when a map requires it and checks if your game version supports it. See T4M and Support for T4M .

Can I install maps on another drive?

Yes, with a custom mods folder in Settings > CoD WaW . This feature is experimental, and World at War only finds the maps when you start it from the UGX Launcher (see Custom WaW Mods Folder ).

What do the states of a map mean?

See Mod States for all states, from "Not installed" to "Installed".

Updates

How do I update the UGX Launcher?

The UGX Launcher updates itself: when a new version is out, it downloads and installs the update and restarts (see Self Updater ). The update mode in Settings > Account decides which versions you get; stable is recommended for most users (see Update Mode ).
