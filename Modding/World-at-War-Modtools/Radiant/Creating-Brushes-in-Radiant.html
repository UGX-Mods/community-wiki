Brushes are the basic building blocks of a map in Radiant: convex shapes with a texture on each face. Walls, floors and ceilings are brushes, and so are invisible helpers like triggers and clips. This page explains the brush types the other World at War guides refer to.

Creating a brush

  1. Deselect everything (Escape).
  2. Select a texture in the texture window. New brushes get the selected texture.
  3. Click and drag in the 2D view to draw the brush, then switch the 2D view to a side view to adjust its height.

Use the caulk texture on every face the player can never see (for example the back of a wall or the bottom of a floor). Caulk faces are not drawn, which saves performance. Many mappers build all brushes from caulk first and texture only the visible faces afterwards.

Structural

Structural brushes form the main shell of the level: the large walls, floors and ceilings. The compiler uses them to split the map into cells, together with portals (brushes with the portal texture on one face and portal_nodraw on the other faces). Only structural brushes can form the walls of a cell, so keep them simple and closed.

Detail

Detail brushes are everything else: trims, beams, furniture, rubble and other small shapes. They do not split the map into cells, which keeps the compile fast and the cell structure clean. Make small or complex brushes detail brushes. You can hide detail brushes with the filter options to check what is left of the structural shell.

Triggers

Triggers are invisible brushes that start something when a player touches or uses them. To create one, draw a brush, right-click in the 2D view and choose a trigger type from the trigger menu, for example:

  • trigger_use : the player presses the use key, for example to buy a door ( Creating a Moving Door Blocker )
  • trigger_multiple : fires every time a player enters it

Radiant gives the brush the trigger texture automatically. Set the KVPs the script expects on the trigger entity.

Clips

Clips are invisible brushes that block movement without being drawn. Use them to smooth out stairs and rough geometry or to keep players out of areas. The clip textures block different things:

Texture Blocks
clip players and AI (not bullets)
clip_player only players
clip_monster only AI
clipweap bullets and grenades, not players or AI
clip_nosight players and AI, and AI cannot see through it

Script Brushmodels

A script brushmodel is a brush (or a group of brushes) that scripts can move, rotate, hide or delete, for example a door or debris that disappears when it is bought. To create one, select the brushes, right-click in the 2D view and choose script > brushmodel . The brushes become one script_brushmodel entity that you can give KVPs like targetname .

The door guides use script brushmodels for the door itself and for its clip: Creating a Moving Door Blocker and Creating a Swinging Door Blocker .
