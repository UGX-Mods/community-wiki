Summary

Finally a new update. This one took a long time, especially because of performance testing and fixing.

Better performance, new Avatar Editor and other great improvements + fixes.

You can now finally upload (or use an URL) and modify the image (crop & filters) before uploading it. Try it out now .

Important highlights from this release

  • New Features
    • Post attachments can be sorted now.
    • New posts attachments can be added easily with drag & drop of one or multiple files
    • Audio / video elements are embedded now (if browser is supported) and better thumbnails
  • Improvements
    • Better "Jump to" list with search term highlight and search keeps hierarchy during search intact now.
      • Before...
      • After...
    • Better explanation for new users why their post / topic is unapproved
    • Better display of deleted users and new avatar for them
    • Reworked the social share buttons & popup (faster and fully working in 2023^^)
    • New radio and checkbox input style (also optimized / faster)
    • Image orientation of uploaded attachments are properly set for the thumbnail
    • Better Discord Sync information, especially if user did not join our Discord yet (or uses a different account).
    • Added latest emojis (v15.1) [twitter is currently unavailable]
    • Removed some javascript / css bloat -> faster page load / smaller page download size
    • Security improvements (some cookies are secure & http only now)
    • (Also updated the UGX Web Chat & some root / landing pages)
  • Fixes
    • Fixed a couple of reported issues from Sentry
    • "Fixed compatibility issues with newer PHP version
  • Development Improvements
    • Removed old dependencies for faster page loads (less resources to load).
    • Migrated to Jira Cloud (API)
    • Migrated Confluence to WikiJS
    • Updated all dependencies with bug & security fixes
    • Cleanup of older images, reduced asset loads and general some housekeeping (project is over 10 years old 😀)
